Type: task
Status: claimed

## Question

El repo local no tiene commits ni remoto, y el destino es publicar en npm. Trabajo manual que desbloquea la publicación:

1. Primer commit del repo (PRD, mapa, skills) en `main`.
2. Crear el repo en GitHub (`gh repo create`) y pushear.
3. Verificar acceso de publicación a npm (`npm whoami`; login si hace falta) y confirmar que `opencode-profile-switcher` sigue libre al momento de publicar.

Parte es AFK (el agente puede hacerlo con `gh`/`npm` si hay auth); si falta auth, checklist HITL para el usuario. El answer registra: URL del repo, usuario npm, estado del nombre.
